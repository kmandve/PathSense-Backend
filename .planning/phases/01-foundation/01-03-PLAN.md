    **Update pathsense/routes/analyze.py** — add POST /analyze endpoint below the existing GET /health:

    ```python
    from fastapi import APIRouter, Request, HTTPException, UploadFile
    import torch
    from PIL import Image, UnidentifiedImageError
    import io
    from pathsense.config import SUPPORTED_CONTENT_TYPES
    from pathsense.services.vision import run_inference_async

    router = APIRouter()

    # ... existing GET /health stays unchanged ...

    @router.post("/analyze")
    async def analyze(file: UploadFile, request: Request):
        # IMG-02: Validate content type
        if file.content_type not in SUPPORTED_CONTENT_TYPES:
            raise HTTPException(
                status_code=415,
                detail=f"Unsupported image type: {file.content_type}. Accepted: JPEG, PNG"
            )

        # IMG-01: Read upload bytes ONCE (Pitfall 4: UploadFile read twice returns empty)
        image_bytes = await file.read()

        # Decode and validate image data
        try:
            img = Image.open(io.BytesIO(image_bytes)).convert("RGB")
        except (UnidentifiedImageError, Exception):
            raise HTTPException(
                status_code=400,
                detail="File is not a valid image or is corrupted"
            )

        # VIS-02: Run inference via vision service (handles resize + VRAM cleanup)
        model = request.app.state.vision_model
        if model is None:
            raise HTTPException(status_code=503, detail="Model not loaded")

        try:
            description = await run_inference_async(model, img)
        except Exception as e:
            # D-09: Return 500 with message for inference failures (fallback is Phase 4)
            raise HTTPException(
                status_code=500,
                detail=f"Inference failed: {str(e)}"
            )

        return {"description": description}
    ```

    Key implementation details:
    - file.content_type checked BEFORE reading bytes (fail fast)
    - image_bytes = await file.read() called exactly ONCE (Pitfall 4)
    - PIL Image.open validates actual image data (not just content-type header)
    - .convert("RGB") ensures consistent color mode for model
    - Model None check returns 503 (same as health check)
    - Inference errors return 500 with detail (D-09, fallback is Phase 4)
    - Image resize happens inside _run_inference (Plan 02), not duplicated here
